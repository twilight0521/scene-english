# Scene English · 入境英语

基于 [Scene-English-PRD-v0.1.md](./Scene-English-PRD-v0.1.md) 实现的手机优先、可运行学习 MVP。面向中文母语成人初学者，界面中文、学习任务英语，先理解，再模仿，再完成场景交流。

## 运行

要求 Node.js 24.15+（使用内置 SQLite）、npm。

```sh
npm ci
npm run dev
```

学习端：http://localhost:5174；业务 API：http://localhost:3001。5174 已设置为固定端口，避免静默切换端口引起来源校验问题。如端口被占用，先关闭对应旧服务。

```sh
npm test          # 状态机与真实 HTTP / SQLite 集成测试
npm run check    # TypeScript 检查
npm run build    # 类型检查 + 生产构建
npm start        # 同一端口 3001 提供页面与 API
```

## 已实现

- 20 个学习单元：4 节基础桥接课，咖啡店、商店、问路、认识朋友各 4 节；教学与迁移任务使用不同定义与目标。
- 首次体验包含目标选择、听音点选演示、起点选择；允许访客试学、跳过和重新体验。
- 看图听音、点选 / 桌面拖动理解、录音回放重录、角色对话、迁移挑战、课后证据与复习完整闭环。
- 槽位状态机接受分步回答、一次填多个信息、更正、请求重复与慢速；必须由用户给出目标信息并确认，角色不能替用户填答案。
- 逐级提示；服务端记录提示条件，严格模式拒绝中文释义，句首 / 完整示范不计独立成功。
- 浏览器原生录音先转为 WAV，服务器校验类型、文件大小与 0.2–30 秒长度；离页 / 切后台停止录音，拒绝权限后可继续文字练习。
- 可选 ASR 异步任务：持久化任务状态、幂等提交、12 秒服务超时、重启后明确失败。低可信或缺少质量信息的结果必须确认，不计独立口语证据。
- 本地 SQLite 持久化，访客 cookie 身份、邮箱密码账号、访客进度合并、进度恢复；密码加盐 scrypt，cookie 为 HttpOnly。
- 分开记录理解、模仿、表达和应对信息；文字 / 手动转写不冒充口语；独立能力至少要求跨两天的三次独立语音迁移证据，其中一次新任务。
- 次日、第 3、7 天的可解释复习；依赖完整提示缩短间隔；复习按历史生成变化任务，每次最多展示 10 项。
- 管理后台：课程 JSON 编辑、预览、新版本草稿、8 项人工审核、发布 / 历史回滚。进行中的会话保留课程快照。
- 学习事件和试学反馈入库，导出记录、删除单条录音及其引用、清除个人学习数据。
- PWA 清单和生产环境 Service Worker：访问并缓存后可离线打开课程、做理解练习及本地录音回放；离线练习不记分、不上传、不伪装口语评估。
- 手机与桌面布局、键盘操作、弹窗焦点约束、减少动态效果。

## 配置

复制 `.env.example` 为 `.env`，按需填写。未配置 ASR 也可以完整使用理解与文字演练。

| 配置 | 用途 |
|---|---|
| `PORT` | API / 生产站点端口，默认 3001 |
| `DATA_DIR` | SQLite 数据目录，默认 `./data` |
| `ADMIN_PASSWORD` | 内容管理密码；不设置则关闭管理登录 |
| `ASR_URL` | 兼容 multipart 转写协议的服务地址 |
| `ASR_API_KEY` | 仅在服务端使用的语音服务密钥 |
| `ASR_MODEL` | 供应商模型名，默认 `whisper-1` |
| `ASR_RESPONSE_FORMAT` | 默认 `verbose_json`；如供应商只支持 JSON 可设 `json` |
| `COOKIE_SECURE` | HTTPS 生产环境设为 `true` |
| `TRUST_PROXY` | 通过本机 HTTPS 反向代理访问时设为 `true`，仅信任 loopback |

管理入口在「我的旅程 → 内容管理后台」，也可打开 `/#admin`。设置密码后重启服务即可启用，不存在内置默认密码。

ASR 返回格式：`{text, segments?: [{no_speech_prob, avg_logprob}]}`。只有每段质量信息完整且通过保守阈值的原始转写才能贡献语音槽位。手动编辑后降为待验证语音。适配层可替换，未依赖语言模型自由判定通关。

## 架构

```text
src/                       React 学习端 / 内容后台
  components/Learning.tsx  五阶段学习播放器
  components/Recorder.tsx  录音与本地回放
  audio.ts                 WAV 标准化
  components/SceneArt.tsx  可组合原创 SVG 场景
shared/
  content.ts               课程与平行 / 复习任务
  engine.ts                确定性对话、证据与复习规则
  types.ts                 共享领域类型
server/
  index.ts                 身份、课程、学习、录音、任务与后台 API
  db.ts                    SQLite 表与事务
  asr.ts                   可替换语音供应商适配器
public/                    PWA、图标与离线缓存
 tests/                    核心状态机和 API 集成测试
```

数据表分别保存用户、令牌、内容版本、会话、尝试、证据、复习、录音、处理任务与事件。课程快照、规则版本、支持方式和槽位来源随尝试保留。提交、最终证据和复习更新在同一事务中提交；重复请求返回原结果。

## 数据和运行边界

- 这是可本地使用的试点 MVP，尚未部署到公开环境。SQLite 适合单实例；生产扩容可保留模块边界并迁移 PostgreSQL / 对象存储。
- 20 节课程是可运行试点脚本，初始状态 `pilot`，并不声称经过英语教学专家审核。正式发布前需由内容负责人完成后台审核。
- 语音播放使用设备英语 TTS，不能保证每台设备的离线声音；失败保留文字。未配置 ASR 时不会伪造识别结果或发音分。
- 槽位识别采用受约束的规则与别名，覆盖课程内表达。复杂语义、口音公平性和真实设备录音 / 供应商质量仍需上线前实测。测试中的语音供应商为受控模拟服务，不代表实测了商用识别质量。
- 原始录音默认最多保留 24 小时：按 23 小时阈值每小时清扫，启动时同步清扫，并删除录音引用与关联任务。离线回放录音只留在当前页面内存。
- 删除音频不删除转写与学习结论；「清除学习数据」会删除这些个人学习记录，但保留账号。导出包含学习记录，不包含密码和密钥。
- 浏览器首页只缓存课程目录，不缓存身份、录音、转写和 API 响应。设备若清除 cookie，访客身份会丢失；需跨设备时注册账号。
- 账号提供基础本地身份与进度同步，不包含邮件验证、找回密码、支付或开放社区。部署公开服务前应接入相应基础设施、备份和真实设备验收。

## 验证

`npm test` 使用独立临时数据库和测试端口，不修改实际学习进度。覆盖 20 节课 / 40 个任务、信息更正、歧义与否定、请求重复、提示独立性、复习与能力门槛，以及会话隔离、重复提交、注册合并、真实 WAV 校验和删除、ASR 任务、课程审核发布与回滚。
